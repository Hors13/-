# ShmulfTyper — сборка APK без Android Studio

1. Создай на github.com репозиторий и загрузи в него всё содержимое этой папки (включая скрытую .github).
2. Вкладка Actions → Build APK → дождись зелёной галочки (2–4 мин).
3. В запуске скачай Artifact "ShmulfTyper-apk" → app-debug.apk → установи на телефон.

Первый запуск: "ВКЛЮЧИТЬ СЛУЖБУ" → включи ShmulfTyper → вернись → "ПОКАЗАТЬ ПАНЕЛЬ".
Синтаксис шаблона: каждая строка = сообщение; *60-80впм* — скорость; *50%* — шанс ошибки в слове.
